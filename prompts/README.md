# 🤖 Prompt Library

Questa directory contiene la **libreria canonica dei prompt** utilizzati nei corsi e nei workshop.

I prompt sono organizzati principalmente per **agente o capability**, in modo da poter essere riutilizzati in corsi e scenari differenti.

---

## 🔎 Researcher

Prompt dedicati alla:

- ricerca approfondita;
- analisi strategica;
- valutazione di scenari;
- analisi di mercato;
- individuazione di opportunità;
- preparazione di briefing;
- supporto decisionale.

➡️ [Researcher Prompt Library](agents/researcher/README.md)

---

## 📊 Analyst

Prompt dedicati alla:

- analisi quantitativa;
- esplorazione dei dati;
- individuazione di pattern;
- identificazione di anomalie;
- simulazione di scenari;
- analisi economica;
- costruzione di business case.

➡️ [Analyst Prompt Library](agents/analyst/README.md)

---

## 🧭 Principio di organizzazione

Un prompt viene mantenuto **una sola volta** all'interno della libreria.

I corsi presenti nella directory [`courses`](../courses/README.md) fanno riferimento a questi prompt senza duplicarne il contenuto.

Questo permette di:

- mantenere una singola versione aggiornata;
- riutilizzare lo stesso prompt in corsi differenti;
- semplificare la manutenzione;
- separare il prompt dal contesto didattico;
- migliorare la consistenza degli esempi utilizzati durante i training.
