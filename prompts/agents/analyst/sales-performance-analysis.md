# 📊 Sales Performance Analysis

**Agent:** Analyst  
**Scenario:** Sales Analytics  
**Origin:** MS-4019

---

## 🎯 Objective

Trasformare un dataset commerciale in evidenze quantitative utili alla strategia aziendale.

---

## 📁 Suggested Dataset

Il dataset può contenere colonne come:

```text
Cliente
Settore
Servizio
Fatturato
Margine
Anno
```

È possibile aggiungere ulteriori variabili disponibili nel dataset reale.

---

## 📝 Prompt

```text
Analizza questo dataset delle vendite.

Prima di procedere verifica:

- struttura del dataset;
- qualità dei dati;
- valori mancanti;
- eventuali anomalie;
- variabili disponibili.

Identifica successivamente:

- servizi con maggiore crescita;
- servizi in contrazione;
- servizi con maggiore marginalità;
- clienti maggiormente profittevoli;
- settori in crescita o contrazione;
- concentrazione del fatturato;
- dipendenza da singoli clienti;
- eventuali anomalie.

Verifica inoltre se esistono relazioni significative tra:

- settore;
- tipologia di servizio;
- fatturato;
- marginalità.

Confronta quando possibile l'andamento nel tempo.

Produci le visualizzazioni che ritieni maggiormente utili per comprendere i risultati.

Non limitarti a descrivere i dati.

Identifica:

- pattern;
- anomalie;
- trend;
- segnali che potrebbero avere implicazioni strategiche.

Distingui chiaramente tra:

- evidenze direttamente osservabili nei dati;
- interpretazioni;
- ipotesi che richiedono ulteriori informazioni.

Concludi indicando le cinque evidenze che dovrebbero maggiormente influenzare la strategia commerciale.

Per ciascuna spiega perché potrebbe essere rilevante per il business.
```

---

## 💡 Strategic Value

Analyst trasforma un dataset operativo in **evidenze quantitative utilizzabili per una decisione aziendale**.

La demo non deve quindi concentrarsi semplicemente sulla capacità di creare grafici, ma sulla capacità di individuare segnali che meritano un approfondimento strategico.
