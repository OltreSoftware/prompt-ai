# 📊 Microsoft 365 Copilot Analyst

Questa directory contiene prompt progettati per evidenziare il valore di **Analyst** nell'analisi dei dati aziendali.

Analyst è particolarmente utile per:

- esplorare dataset;
- individuare pattern;
- identificare anomalie;
- confrontare variabili;
- creare visualizzazioni;
- costruire scenari quantitativi;
- supportare decisioni attraverso evidenze numeriche.

## 🧠 Researcher vs Analyst

Una distinzione utile è:

> **Analyst individua il segnale nei dati.**

> **Researcher cerca di capire cosa significa quel segnale nel contesto aziendale e di mercato.**

In sintesi:

**Analyst → Evidence**

**Researcher → Context**

**Human → Decision**
