# 🔎 Microsoft 365 Copilot Researcher

Questa directory contiene prompt progettati per evidenziare il valore di **Researcher** in scenari aziendali.

Researcher è particolarmente utile quando è necessario combinare informazioni provenienti da più fonti, analizzare un problema complesso, confrontare evidenze e produrre una sintesi orientata alla decisione.

## 💡 Quando utilizzare Researcher

Researcher è particolarmente indicato quando la domanda non è semplicemente:

> **"Cosa sappiamo?"**

ma piuttosto:

> **"Cosa significano queste informazioni per la nostra azienda e quale decisione dovremmo prendere?"**

---

## 🧠 Pattern consigliato

Un buon prompt per Researcher tende a contenere:

1. **Contesto**
2. **Decisione da supportare**
3. **Fonti da analizzare**
4. **Criteri di confronto**
5. **Rischi e opportunità**
6. **Scenari alternativi**
7. **Raccomandazione finale**

L'obiettivo non è ottenere semplicemente più informazioni, ma trasformare le informazioni disponibili in **evidenze utili alla decisione**.
