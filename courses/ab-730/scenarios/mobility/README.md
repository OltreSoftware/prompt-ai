# AB-730 - Mobility Scenario

Questo scenario propone una contestualizzazione di alcuni prompt
dei laboratori Microsoft AB-730 per un'organizzazione che opera
nel settore della mobilità locale.

Gli esempi prendono in considerazione attività quali:

- mobilità pubblica e privata;
- trasporto scolastico;
- servizi di trasporto a chiamata;
- mobilità accessibile;
- mobilità elettrica;
- servizi rivolti a enti locali e cittadini.

Lo scenario è volutamente indipendente da organizzazioni specifiche
e può essere ulteriormente personalizzato durante l'erogazione
del corso.

## Obiettivo

Lo scopo non è creare una versione alternativa dei laboratori
Microsoft.

Vengono modificati soltanto i prompt nei quali la
contestualizzazione può rendere l'esercitazione più significativa.

In alcuni casi il prompt originale viene mantenuto intenzionalmente
per mostrare come Microsoft Copilot possa utilizzare il contesto
già disponibile nella conversazione.

## Convenzioni

🔵 **Prompt originale Microsoft**

Prompt presente nel laboratorio ufficiale.

🟢 **Prompt contestualizzato**

Possibile alternativa in italiano adattata allo scenario Mobility.

🟣 **Prompt aggiuntivo**

Prompt facoltativo che non sostituisce il laboratorio Microsoft,
ma permette di applicare quanto appreso allo scenario Mobility.

⚪ **Nessuna modifica consigliata**

Utilizzare il prompt previsto dal laboratorio ufficiale.
