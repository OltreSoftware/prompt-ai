# AB-730 - AI Business Professional

Questa sezione raccoglie materiali integrativi e scenari di
contestualizzazione utilizzabili durante il corso Microsoft AB-730
AI Business Professional.

## Laboratori ufficiali

I materiali presenti in questo repository non sostituiscono i
laboratori ufficiali Microsoft.

I laboratori devono essere svolti seguendo le istruzioni disponibili
nel repository MicrosoftLearning:

https://github.com/MicrosoftLearning/AB-730-AI-business-professional/tree/main/Instructions/Labs

## Scenari

Gli scenari propongono possibili adattamenti di alcuni prompt dei
laboratori ufficiali a specifici contesti aziendali.

L'obiettivo è mostrare come contestualizzare un prompt mantenendo
invariati:

- obiettivo dell'esercitazione;
- strumenti utilizzati;
- struttura del laboratorio;
- funzionalità Microsoft Copilot oggetto dell'attività.

### Scenari disponibili

- [Mobility](./scenarios/mobility/README.md)

## Come utilizzare gli scenari

Segui normalmente il laboratorio Microsoft.

Quando nello scenario è indicato un prompt alternativo, puoi
utilizzarlo al posto del prompt originale per contestualizzare
l'esercitazione.

I prompt non esplicitamente modificati devono essere eseguiti come
previsto dal laboratorio ufficiale.
