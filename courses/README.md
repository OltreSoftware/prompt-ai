# 🎓 Training Courses

Questa directory contiene i percorsi didattici che utilizzano i prompt presenti nella libreria.

I prompt **non vengono duplicati all'interno dei corsi**.

Ogni corso contiene invece:

- scenari;
- obiettivi didattici;
- sequenza delle attività;
- collegamenti ai prompt canonici;
- elementi da osservare durante la demo;
- messaggi chiave da evidenziare durante la formazione.

## 🧭 Principio

La directory `courses` rappresenta il **percorso didattico**.

La directory [`prompts`](../prompts/README.md) rappresenta invece la **libreria canonica**.

Questo permette allo stesso prompt di essere utilizzato in più corsi senza duplicarne il contenuto.
